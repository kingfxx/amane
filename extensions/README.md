# 独立扩展

两个扩展分别安装和更新. 构建入口为根目录 `just package-extensions`, 产物位于 `dist/extensions/`.

## NFO 导入插件

NFO 插件 0.2.0 需要支持 Import API v2 的宿主. 宿主继续兼容 v1 导入插件及旧快照; 未包含导入接口的上游版本无法加载本插件, 影片来源与播放插件不受影响.

1. 启动更新后的 Amane, 在「插件」页上传 `local.nfo.zip`, 或通过服务器路径选择 `extensions/nfo-import` 目录.
2. 在「本地 NFO 导入」卡片点击「导入本地元数据」, 选择服务器上的目录; 递归默认关闭.
3. 预览影片与附属文件. 指定媒体库时登记该库内的正片; 不指定时只导入元数据和附属资源.
4. 勾选影片并执行, 在任务页查看结果、失败原因与保存的本地预览片路径.

图片复制至 Amane 资源存储, 相同内容去重. 预告片默认使用 NFO 远程链接; 本地预览片只保存路径, 不复制、不读取视频内容, 不提供自动本地播放回退. 正片不复制. 目录和文件必须位于宿主授权的安全目录内, Docker 中填写容器可访问路径.

预览时由插件在宿主分配的 `data/import-cache` 目录保存 NFO、图片及元数据快照, 导入与重试读取本地副本. 视频只保留原路径和文件属性. 来源内容变化后需重新预览; 缓存缺失或不兼容时不会自动重新下载. 先更新宿主, 再安装新版插件; 更新前已提交的任务继续使用对应快照.

默认只补充未锁定空字段; 勾选「覆盖未锁定的已有字段」后, 使用导入的非空值替换已有值, 缺失字段不清空. 锁定字段、用户标签和评论始终保留. 导入不会发起刮削或整理, 不修改源文件. 已导入数据在插件卸载后保留. 本地来源与预览片路径还可通过 `GET /api/imports/{metadata_id}/records` 查询.

插件可在内存中兼容未转义的 `&` 和以数字开头的自定义标签, 并在预览中提示; CDATA 与注释正文保持不变. DTD、外部实体及其它不支持的 XML 结构错误仍会拒绝导入.

## 115 浏览器播放脚本

需要 Chrome、篡改猴、115master, 并在同一浏览器配置中登录 115. 本扩展独立于 NFO 插件, 不需要修改 Amane 播放接口或配置服务端 Cookie.

1. 在篡改猴中新建脚本, 导入生成的 `amane-115.user.js` 内容并保存.
2. 默认匹配本机 8000 端口的 localhost 与 127.0.0.1. 使用其它域名、IP、端口或 HTTPS 时, 在脚本头部将 `@match` 设置为自己的 Amane 地址, 保留末尾 `/*`.
3. 进入影片详情页, 查看页面顶部的 115 查询状态; 番号取自详情 API 的 `metadata.number`. 单个匹配直接播放, 多个匹配选择文件后播放.
4. 登录变化或文件变化后点击「重新查询」清除当前番号缓存; 播放会在新标签页打开 Master 链接.

脚本仅请求 115 搜索接口, 不读取、导出或保存 Cookie. 请求带凭据的实际行为受 Chrome 和篡改猴权限、Cookie 策略影响. 搜索失败时根据提示处理登录、网络或访问限制; 不以空结果代替错误. 原生桌面客户端与 Android WebView 不包含篡改猴, 不适用此脚本.

## 验证与更新

`just test-extensions` 执行导入解析、数据库写入、HTTP 集成和浏览器脚本匹配测试. 115 登录态搜索、篡改猴注入与 Master 接管仍需要在用户实际浏览器中验收, 自动测试不代表真实账号播放已通过.

主机通用接口、NFO 插件与浏览器脚本分别维护. 更新主机前备份 SQLite 与资源目录; 插件更新不需要替换用户源目录. 浏览器脚本停用后其页面控件不再注入.
